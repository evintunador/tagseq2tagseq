% Contribution list.
\paragraph{Contributions.}
\begin{itemize}
  \item A pretraining framework that packs documents by graph traversal and grants
        \emph{link-position-gated} cross-document attention along explicit edges
        (\Cref{sec:method}).
  \item Compute-controlled ablations (\concatlink, \concat) that attribute the gain
        to the linking inductive bias rather than to extra attention FLOPs.
  \item Evidence across three edge modalities---Wikipedia hyperlinks, code imports,
        arXiv citations---that cross-document attention beats flat concatenation of
        the same linked content on benchmarks built to require it, while remaining
        neutral on single-document benchmarks.
  \item A density-aware batch scheduler that removes the DDP rank imbalance caused
        by variable mask sparsity, for a $1.45\times$ mean step speedup.
  \item An inference/generation loop that resolves generated links against the
        corpus and injects the target document, mirroring training.
\end{itemize}
